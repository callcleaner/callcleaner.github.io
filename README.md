# CallCleaner project page

Static page (Bootstrap 4, same style as cwomp.github.io). Audio examples and spectrograms in `media/` plus
`examples.json` are generated by `scripts/make_project_page.py` in the research repo
(`morrisalp/bioacoustic-enhancement`); `assets/overview.png` and `assets/tradeoff.png` are rendered from the
paper's Fig. 1 and Fig. 2.

Preview locally: `python3 -m http.server` here, then open http://localhost:8000 (the examples load via fetch,
so opening index.html as a file won't show them).
